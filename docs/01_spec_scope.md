# 01 Spec & Scope (v2.0)

## Цель проекта
Создать локальный статический сайт-стенд барбершопа для UI/UX-ревью с намеренно встроенными дефектами, которые воспроизводятся и фиксируются в документах.

## Целевая аудитория
1. Frontend-разработчик (автор итераций).
2. Ревьюеры UX/A11y/Content.

## In Scope
1. Статический интерфейс барбершопа на `HTML/CSS/JS`.
2. Два обязательных сценария:
- основной: запись на визит через hero CTA и форму;
- альтернативный: переход по меню к услугам/мастерам и возврат к форме.
3. Поддержка `happy-path`, `invalid-path`, `recovery-path` для обоих сценариев.
4. Намеренно встроенные 4 ошибки:
- `UX-BRB-001` (Major),
- `UX-BRB-002` (Major),
- `UX-BRB-003` (Minor),
- `A11Y-BRB-001` (Minor).

## Out of Scope
1. Backend, внешние API, БД.
2. Авторизация, платежи, production-хостинг.
3. Автоматический e2e-контур.

## Критерии качества
1. UX: оба сценария воспроизводятся end-to-end.
2. A11y: базовая клавиатурная проходимость и видимый фокус.
3. Content: единый русский tone of voice без `lorem/todo/tbd`.
4. Текущая релизная цель: осознанный `FAIL` для учебного разбора намеренных ошибок.

## Ограничения
1. Локальный запуск (`index.html` или `python -m http.server`).
2. Стек фиксирован: `HTML/CSS/JS`.
3. Модель приемки: `Pass/Fail`.
